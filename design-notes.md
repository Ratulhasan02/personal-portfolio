# Design Notes

## Color Choices
The portfolio uses a dark, minimal palette built around deep charcoal backgrounds, soft off-white text, and a warm amber accent. The primary colors are `#0d0e10` and `#070708` for the background, `#ecebe6` for primary text, and `#9c9c95` / `#6c6d68` for muted supporting text. The accent gold tone (`#e8b65a`, with a slightly brighter hover state) is used sparingly for highlights, active navigation states, and call-to-action buttons. This combination creates a polished, modern contrast that keeps the interface readable while adding focus and warmth without overwhelming the content.

## Font Choices
The site uses `Fraunces` for headings and display text, `IBM Plex Sans` for the main body content, and `IBM Plex Mono` for small metadata and technical tags. The serif display font gives the portfolio a more editorial, premium feel for names and section titles, while the clean sans-serif body type keeps reading comfortable and modern. The mono style is used for small labels and project tags to provide technical clarity and visual rhythm. Together, these choices support a clean, readable, contemporary portfolio look that balances personality with usability.
